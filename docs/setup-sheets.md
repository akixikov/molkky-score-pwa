# チーム共有スプレッドシートの準備

チームの記録を 1 つの Google スプレッドシートに集めるための手順です。
**シートを用意するのは代表者 1 人だけ**。メンバーは「メンバーの設定」だけ行います。

- ウェブアプリの URL と合言葉は、チームのメンバーにだけ個別に伝えてください（公開の場所に書かない）。
- シートの共有はメンバーの Google アカウントだけにし、「リンクを知っている全員」にはしないでください。
- 1 試合（練習は 1 ゲーム）を記録するのは 1 台だけにします。記録した端末だけがその試合を修正・削除できます。

## 代表者：シートを作る（初回だけ）

1. Google ドライブで新しいスプレッドシートを作る（名前は自由。例「モルック チーム記録」）
2. メニュー **拡張機能 → Apps Script** を開く
3. エディタに最初からあるコードをすべて消し、[`apps-script/Code.gs`](../apps-script/Code.gs) の中身を貼り付けて保存（💾）
4. スプレッドシートのタブに戻って再読み込みすると、メニューに **Mölkky Scorer** が出る
5. **Mölkky Scorer → Set passphrase** を選ぶ
   - 初回は「承認が必要です」と出るので、**続行 → 自分のアカウント → 「このアプリは Google で確認されていません」→ 詳細 → （プロジェクト名）に移動 → 許可**
   - もう一度 **Set passphrase** を選び、合言葉を入力して OK
6. Apps Script のエディタに戻り、**デプロイ → 新しいデプロイ**
   - 歯車 → **ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - **デプロイ** を押し、表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー
7. アプリの **Team sync** に URL・合言葉・自分の名前を入れて **Test connection** →「Connected.」→ **Save**
8. これまでの記録も送るなら **Resend all my matches**。シートに `Games` と `Throws` が作られ、行が入ることを確認
9. スプレッドシートの **共有** で、メンバーを **閲覧者** として追加
10. URL と合言葉をメンバーに個別に伝える

### あとから必要になる操作
- **コードを更新したとき**：Apps Script で **デプロイ → デプロイを管理 → 鉛筆 → バージョン：新バージョン → デプロイ**。URL は変わりません
- **合言葉を変えるとき**：**Mölkky Scorer → Set passphrase** で入れ直し、メンバーにも伝えて各自のアプリで更新してもらう
- `Games` と `Throws` はアプリが書き込むシートです。手で編集せず、集計は別のシートから数式で参照してください

## メンバーの設定

1. アプリのホーム下の **Team sync** を開く
2. 代表者から聞いた **Web app URL** と **Passphrase**、自分の名前（**Your name**）を入れる
3. **Test connection** で「Connected.」と出たら **Save**
4. すでにこの端末で記録した試合があれば **Resend all my matches**

以降は、記録を変更するたびに自動でシートに送られます。電波がないときは端末に残り、つながったときに送られます。
ホームの **Team sync** の横に「○ unsent」（未送信の件数）や「Synced 時刻」が出ます。

チームの他の人の記録は、アプリを開いたときと送信のあと（最短 1 分おき）に取り込まれ、一覧に「by 名前」付きで出ます。
すぐに見たいときは **Team sync → Sync now**。他の人の記録は読むだけで、修正・削除は記録した人の端末でだけできます。
